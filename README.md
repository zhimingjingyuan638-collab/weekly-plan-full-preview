# 週案アプリ フル版（BYOC）動作確認用プレビュー

> **本リポジトリは作者本人の動作確認用です。** 有料配布前の検証目的でPublicにしています。
> 中身は今後変わります。利用は自己責任で。

## 使い方

1. このページ（GitHub Pages）を **PC** と **スマホ** の両方で開く
2. それぞれで「Googleドライブと連携」→ 同じGoogleアカウントでログイン
3. PCで週案を入力 → スマホで開き直すと同じ週案が見える（Googleドライブ経由の同期）

## データ保存場所

- **週案データ**：あなたのGoogleドライブの `週案アプリ_データ/data.json`
- 作者のサーバには **一切送信されません**
- ログアウト・連携解除すればドライブ側のデータは残ったまま、ローカル参照は切れる
